# 검증 기록

2026-11-03 · 로컬 0.1.0

## 수행함

- Node 24.22.1, TypeScript 5.9.3 타입 검사 통과.
- Vite 8.0.13 프로덕션 빌드 통과. React / React DOM 19.2.6.
- Node 테스트 7개 통과: 초기 집계, 복합 필터, 완료와 체크리스트의 분리, 불변 스냅숏, 날짜 경계, 빈 단계·없는 ID, 완료 확인 판정.
- 테스트의 불변 스냅숏 검사는 모델 함수의 불변성을 검증합니다. 화면 되돌리기는 아래 실제 UI 검사로 별도 확인했습니다.
- 독립 HTML을 실제 Ego Lite 브라우저에서 파일 URL로 열어 렌더링 확인.
- 실제 UI에서 Q-001의 미완료 단계 2개 확인창 → 완료 → 전체 완료 3/12에서 4/12, 오늘 마감 2에서 1, 담당자 미완료 2에서 1로 변경 확인.
- 되돌리기 실행 후 상태, 집계, 체크리스트 1/3, 활동 기록이 복원된 것을 직접 확인.

- 실제 UI에서 검색 0건 안내, 새 퀘스트 생성, 200% 확대와 좁은 화면 상세 복귀를 확인했습니다.
- Flint의 소스 리뷰 후 정보 글자 크기, 행 선택 의미, 외부 링크 새 탭, 중간 폭의 마감 표시를 수정하고 타입 검사·7개 테스트·빌드를 다시 통과했습니다.
- 일반 테마 전환 후 동일한 데이터와 화면 흐름이 유지됨을 확인했습니다.

- 수정 후 새 퀘스트 생성 → 되돌리기에서 전체 13→12개, 오늘 마감 3→2개, 선택 항목 Q-013→Q-001 및 빈 활동 기록 복원을 확인했습니다.

## 제약

- 레지스트리 네트워크 정책으로 새 패키지 설치가 차단되어, 기존 로컬 의존성을 링크해 빌드했습니다. 기존 프로젝트의 소스는 변경하지 않았습니다. dev 캐시는 이 프로젝트 안에 분리했습니다.
- 새 컴퓨터에서의 clean install과 package-lock 생성은 아직 검증하지 않았습니다.
- 이 환경의 빌드 폴더 삭제 제한 때문에 재빌드에는 `vite build --emptyOutDir false`를 사용했습니다. 공개 HTML은 새 빌드의 번들만 참조하도록 생성했습니다.
- 이 환경은 로컬 서버 포트도 차단합니다. 서버 실행 성공을 주장하지 않고 독립 HTML의 실제 UI를 검사했습니다.
- 실제 스크린리더, 모든 브라우저·모바일 기기, 다중 사용자 동시 편집, 트래픽 성과는 검증 범위 밖입니다.

이 기록은 직접 관측한 범위만 뜻합니다. 코드 검사 통과는 사용자 연구나 운영 품질 인증이 아닙니다.
