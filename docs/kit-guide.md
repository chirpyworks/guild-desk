# Guild Desk를 바꾸는 법

## 상태 모델

`todo`(대기), `active`(진행 중), `blocked`(막힘), `done`(완료)를 사용합니다. 어떤 상태에서도 다른 상태로 전환할 수 있습니다. 완료 시 남은 단계가 있으면 UI가 확인을 요청합니다. 판정 함수는 `needsCompletionConfirmation()`입니다. 이는 협업 서버의 권한 규칙이 아닙니다. “다시 진행하기”는 항상 진행 중 상태로 전환합니다. 직전 상태의 복원은 되돌리기를 사용하세요.

- 기한 지남 = 로컬 날짜보다 마감일이 앞서고 상태가 완료가 아님.
- 오늘 마감 = 오늘과 마감일이 같고 상태가 완료가 아님.
- 멤버의 미완료 수 = 해당 담당자의 대기·진행·막힘 합계.
- 전체 완료율 = 완료 퀘스트 / 전체 퀘스트.
- 체크리스트 진척 = 체크된 단계 / 전체 단계. 단계가 없으면 0/0.

숫자 필터 탭은 항상 **전체 길드**를 기준으로 셉니다. 목록의 표시 건수는 검색·담당·상태 조건을 모두 적용합니다. 상단의 길드 진행률은 필터와 독립적인 전체 요약입니다. 선택한 항목이 필터에서 사라져도 상세를 유지하며 필터 밖이라는 안내를 표시합니다.

## 테마

`src/styles.css`의 `:root`가 RPG 테마 기본값이고 `.plain`이 프레임을 단순화한 일반 테마입니다. 픽셀 캐릭터는 두 테마에 남아 있으며, 테마 토큰 교체의 예시입니다. `--navy`, `--paper`, `--ground`, `--purple`, `--frame`, `--radius`, `--shadow`를 바꾸면 전체 인상이 달라집니다. `.window-title`, `.primary`, `.guild-track`은 프레임과 베벨 표현입니다.

게임 제목을 연상시키는 영문 라벨은 시스템 고정폭 글꼴을 사용합니다. 별도의 픽셀 폰트를 번들하지 않았습니다. 한글 설명은 운영체제의 한글 글꼴로 렌더링합니다. OS에 따라 글꼴 모양은 달라집니다.

## 데이터 교체

1. `makeDemo()` 대신 `Quest[]`를 읽는 어댑터를 연결합니다.
2. 마감일은 `YYYY-MM-DD` 로컬 날짜입니다. 서비스에서 사용할 기준 시간대를 먼저 정하세요.
3. `changeQuest()`는 새 객체를 반환하는 순수 함수입니다. 서버와 연결할 때는 성공·실패·재시도 상태를 별도로 둡니다.
4. 예제의 되돌리기는 메모리 스냅숏 복원입니다. 외부 API의 변경을 취소하지 않습니다.
5. 영구 저장을 추가한다면 저장 실패, 버전 충돌, 삭제·복원 정책을 함께 구현합니다.

## 화면 조립

`GameWindow`는 프레임과 제목 바를, `Party`는 담당자 필터를, `StatusBadge`는 텍스트와 기호가 있는 상태 표시를 제공합니다. `ProgressBar`의 의미는 체크리스트 완료 개수입니다. `Avatar`와 `PixelIcon`은 장식이며 보조기술에서 읽지 않습니다. 실제 이름과 행동은 인접한 텍스트로 제공합니다.

현재 버전은 1개 앱을 복제해 바꾸는 소스 킷입니다. 무스타일 headless 라이브러리, 패키지 레지스트리 배포, 완성된 제품 운영 시스템은 범위 밖입니다.

예제 기한은 처음 열 때의 로컬 날짜를 기준으로 생성됩니다. 오늘·지연 판정은 탭을 열어 둔 동안 현재 로컬 날짜에 따라 갱신됩니다.
