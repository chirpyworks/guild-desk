# 공개 전 보안·개인정보 점검

2026-11-03 · Guild Desk 0.1.0

- 공개 대상 파일을 명시한 허용 목록으로만 배포합니다. 작업 폴더 전체를 업로드하지 않습니다.
- 예제 이름 4개와 프로젝트·과제는 직접 만든 합성 데이터이며, 실제 연락처·고객 자료·업무 기록을 가져오지 않았습니다.
- 소스, 문서, 독립 HTML, GitHub Pages HTML에서 인증키·토큰·개인키·이메일·전화번호·로컬 사용자 경로·내부 대화 링크 패턴을 검사했습니다.
- 검토용 원문, 비공개 협업 대화 링크가 있는 내부 메모, node_modules, 캐시, 환경 파일, 로컬 Git 이력은 공개 대상에서 제외했습니다.
- 공개 링크는 프로젝트 GitHub와 공개 블로그를 위한 링크입니다. 번들의 React 문서 링크와 표준 XML/SVG 네임스페이스는 라이브러리에서 사용합니다.
- 사용자 입력은 React 텍스트로 렌더링합니다. 사용자 입력을 HTML로 삽입하거나 코드로 실행하는 경로가 없습니다.
- 앱은 계정·연락처를 요청하지 않습니다. 분석 SDK·쿠키·영구 저장·외부 API 전송을 추가하지 않았습니다. 외부 블로그 링크를 사용자가 열면 해당 사이트의 정책이 적용됩니다.

이 기록은 공개 파일에 대한 패턴 검사와 직접 검토의 범위입니다. 모든 취약점이 없다는 보증이나 외부 보안 감사는 아닙니다. 후속 변경·데이터 교체 시 다시 검사해야 합니다.
